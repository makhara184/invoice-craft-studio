# InvoiceCraft Studio

A zero-dependency, print-ready client invoice studio supporting multi-currency formatting (`USD`, `INR`, `EUR`, `GBP`, `AED`), live tax math, and clean PDF output via browser print styles.

## Quick Start
Open `index.html`, enter your invoice details, and click **Print / Save PDF**.
